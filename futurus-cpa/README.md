# Página CPA 2026 — Faculdade Singular Futurus

Site estático pronto para hospedagem na Vercel.

## Publicação
1. Abra esta pasta no VS Code.
2. Envie `index.html` e `logo-futurus.png` para a raiz de um repositório no GitHub.
3. Na Vercel, selecione **Add New → Project** e importe o repositório.
4. Escolha **Other** como framework (se solicitado), mantenha a pasta raiz como `/` e clique em **Deploy**.

Não há necessidade de `npm install` nem de comando de build.
